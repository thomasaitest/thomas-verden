# Thomas-verden

Privat hobbyprosjekt: en futuristisk by-kopi av Heddas verden (Vite + TypeScript + three.js).

**Ikke publisert.** Kjør lokalt:

```bash
npm install
npm test
npm run dev
```

Fremgang lagres i `localStorage` under nøkkelen `thomasverden-save-v1` (egen nøkkel, kolliderer ikke med Heddas verden).
