# UAT — Thomas-verden (iPhone Safari)

Live: https://thomasaitest.github.io/thomas-verden/

Kryss av når du har sjekket på iPhone (Safari):

1. [ ] Siden laster på `https://thomasaitest.github.io/thomas-verden/` uten blank skjerm
2. [ ] Plaza synes: fontene, butikkfasader og himmel er synlige
3. [ ] Figur-knappen (Avatar) åpner tilpasning med Klær / Hår / Tilbehør og Ferdig
4. [ ] Du kan gå inn i huset og se stuen (sofa / vindu)
5. [ ] Du kan kjøre svevebil (Kjør) på veien uten at spillet kræsjer
6. [ ] Touch-styring (joystick / hopp) fungerer
7. [ ] Lyd av/på og HQ-knapp reagerer
8. [ ] Ingen rød feilmelding i skjermen ved vanlig spilling i ca. 1 minutt
